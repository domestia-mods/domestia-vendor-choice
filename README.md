<h1 align="center">Domestia Vendor Choice</h1>

<p align="center">
  Owner-protected trading tools.
</p>



A Minecraft Fabric mod that adds owner-controlled vendor machines and vendor safes.

## Features

- **Vendor Machine**
  - Owner-controlled configuration interface.
  - Public sales interface.
  - Stock, price, payment, and vault logic.
  - Front panel item display.
  - Built-in vanilla sound effects.
  - PBR-ready textures with normal and specular maps.

- **Vendor Safe**
  - Owner-only 27-slot storage.
  - Owner name and custom anvil label rendering.
  - Operator break access without content access.
  - PBR-ready textures with normal and specular maps.

## Requirements

- Minecraft: 1.21.x
- Fabric Loader
- Fabric API

## Status

Beta. This mod is currently tested on the Domestia server.
